# Phase 8 governance artifacts

These files are implementation aids and provenance references.

- `eu_ai_act_crosswalk.json`: public-law engineering crosswalk and current high-risk timeline.
- `iso42001_crosswalk.json`: high-level AIMS themes only; it does not reproduce ISO/IEC 42001.
- `ai_inventory_template.json`: example AI inventory payload.
- `credential_trust_profiles.json`: credential trust/verification boundaries.

Do not treat these files as legal advice, an ISO certification checklist, a conformity assessment,
or a regulator determination.
